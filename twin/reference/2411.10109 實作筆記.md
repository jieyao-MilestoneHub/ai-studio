# 用自陳資料做個體模擬：資料、建構、評測與坑點

> 整理自 arXiv:2411.10109 — Park, Zou, Kamphorst, Egan, Shaw, Hill, Cai, Morris, Liang, Willer & Bernstein,
> *LLM Agents Grounded in Self-Reports Enable General-Purpose Simulation of Individuals*
> （原題 *Generative Agent Simulations of 1,000 People*）
> https://arxiv.org/abs/2411.10109

**一句話結論：** 決定孿生品質的不是模型大小、也不是 persona prompt 寫得多花俏，而是**自陳資料的深度與可靠度**。全程**沒有任何微調**，純粹是把訪談逐字稿 + 專家反思塞進 GPT-4o 的 context。

---

## 階段 01 · 資料：資料是怎麼被生產出來的

### 關鍵數字

| 項目 | 數值 | 備註 |
|---|---|---|
| 受訪者 | 1,052 | 招募 1,300,預留 20% 流失 |
| 訪談長度 | ≈120 分鐘 | 語音對談,非填表 |
| 逐字稿(受訪者側) | 6,491 字 (SD 2,541) | |
| 追問題數 | 81.71 題 (SD 54.39) | 腳本只有 99 題 |
| 報酬 | $60 + $30 | 另加賽局獎金 $0–10 |
| 回測 | 2 週後 | 同一份量表整套重做 |

### 訪談協定:刻意不是自己設計的

採用 American Voices Project 的(略為精簡)社會學訪談腳本,涵蓋童年、教育、家庭關係、重大生命事件,到對社會議題的看法。**關鍵:腳本由外部研究者設計、與後面所有評測任務無關**——不是挑出「最能預測 GSS 的問題」。這是最容易被忽略、卻最該抄的方法論選擇。

### AI 訪談員的工程細節

- 語音介面:OpenAI TTS 出題、Whisper 轉錄、GPT-4o 決定追問,全程在 **4 秒內**回應以維持對話感
- 靜音超過 **4 秒**視為受訪者說完(畫面脈動圓圈淡出、停止錄音)
- 每個題組手動設**時間預算**,讓總長收斂在兩小時
- 反思模組即時彙整對話,模型只有兩個動作:`前進到下一題` 或 `追問`
- 訪談員自己講了 5,372.59 字(SD 2,406)——追問本身佔大量 token,成本要算進去
- 研發過程:2023 年 8–11 月三輪迭代,每輪 10 場真人 + 25 場 AI 訪談,由受過社會科學訓練的成員逐份比對 AVP 真人訪談稿

### 評測用的量表電池(「標準答案」)

- **GSS 核心模組**:177 題類別題 + 6 題數值題(排除條件題、選項 >25 的題、開放式題)
- **BFI-44**:44 題人格量表,Likert
- **五個經濟賽局(真錢)**:獨裁者($5)、信任賽局先手($3、三倍)、信任賽局後手、公共財($4、翻倍)、囚徒困境($6/$8/$2/$4)
- **五個複製實驗**:從 Camerer 等人的大規模複製計畫挑出「純文字/圖片可描述」且 1,000 人內有檢定力的研究
- Wave 1 中位數 55 分鐘、Wave 2 中位數 50 分鐘(Qualtrics 線上施測)

### 資料清理:把「作弊題」挖出來

訪談裡可能已直接講過 GSS 的答案。用 GPT-4.1 分類器掃過 **54,694 組**「GSS 題 × 訪談題」配對找重複與近似措辭,再經人工複核,**移除 27 題**,最終評測集 **150 題**(平均 3.31 個選項,SD 1.58;隨機猜測 = 0.30)。量表型 agent 另外排除:GSS 同一題本身,以及 Big Five 中**與待測題同一面向**的所有題目。

## 階段 02 · 建構:資料怎麼變成 agent(沒有微調)

整套是 prompt engineering + 記憶結構,底模一律 GPT-4o。沒有 LoRA、沒有 SFT、沒有 embedding retrieval 花招。

### Expert Reflection:整篇最值得抄的模組

對每位受訪者,先離線生成四組「專家觀察」,各 **5–20 條**:

1. **心理學家** — 人格特質、動機、對自主性的偏好
2. **行為經濟學家** — 財務目標、決策模式
3. **政治學家** — 意識形態立場、政策看法
4. **人口學家** — 社經地位、就業、收入、家戶組成

反思**只生成一次並存起來**。查詢時先讓模型判斷「這題該由哪位專家回答」,然後**只取那位專家的全部反思**放進 prompt。這是很便宜的「主題式路由」,比 embedding 檢索更好解釋,也更容易換成自己的專家組。

### Context 組裝

逐字稿塞不進 context,實際餵進去的是:**反思筆記 + 逐字稿最後 5,000 字元**。做實驗題時,再把 agent 收到的刺激材料與先前動作以自然語言接在自陳資料後面。

### 查詢時的四步 CoT

1. **描述會選每個選項的是哪種人** — 先把選項空間人格化,避免模型直接跳答
2. **逐一推理這位受訪者為何可能選它** — 對每個選項都生成理由,強迫考慮反例
3. **比較哪個選項最能預測他的回答** — 這裡才做取捨
4. **輸出實際預測** — 數值題簡化為:解讀範圍 → 推理 → 直接給值

### 五種 agent 變體(對照組設計)

- **Demographic**:只給年齡、性別、種族、政治傾向(大多數現有研究的做法)
- **Persona**:受訪者自己寫一段自我介紹(背景、個性、人口統計)
- **Interview**:完整訪談 + 反思
- **Survey**:結構化量表回答 + 反思
- **Survey + Interview**:兩者都給

## 階段 03 · 評測:Normalized accuracy 是這篇真正的貢獻

人自己兩週後回答同一題,也只有 **79.53%** 一致。所以「準確率 65.67%」單看毫無意義。作法:

```
normalized accuracy = agent 命中率 ÷ 本人兩週後自我一致率
```

值為 1 代表:這個 agent 預測你,跟兩週後的你預測自己一樣準。連續型指標同理用相關係數相除。

### 各 agent 變體表現

| Agent | GSS | Big Five | 經濟賽局 | 實驗效果量 r |
|---|---|---|---|---|
| Demographic 基線 | 0.74 | 0.61 | 0.48 | 0.93 |
| Persona 段落 | 0.71 | 0.75 | 0.57 | 0.94 |
| Interview | 0.83 | 0.80 | 0.66 | 0.98 |
| Survey | 0.82 | 0.65 | 0.38 | 0.91 |
| **Survey + Interview** | **0.86** | 0.77 | 0.49 | **0.99** |

GSS 為標準化準確率、其餘為標準化相關。ANOVA:GSS F(4,5255)=577.83, p<.001;Interview 與 Survey 之間無顯著差異(p=.16),Survey+Interview 顯著優於兩者(p<.001)。經濟賽局全體無顯著差異(F=1.63, p=.16)。

### 消融實驗:兩個關鍵數字

- **砍掉 80% 訪談**(120 分鐘只留 24 分鐘):GSS 0.83 → **0.79**(SD 0.11),Big Five 0.73
- **只留條列式摘要**(保留事實、剝掉語言特徵):GSS **0.81**(SD 0.13),Big Five 0.70

兩個都只掉一點點。含義:**驅動預測的是事實內容,不是說話方式,而且資訊量很快飽和。**

### 公平性

用 Demographic Parity Difference(最佳與最差人口群組的表現差距)。GSS 上以**政治意識形態**落差最大:demographic 13.75% → interview 8.60% → survey 6.22% → 合併 7.09%。種族從 3.39% 降到約 2%,性別各組 <1%。**縮小了,但沒消除。**

核心分析事前在 OSF 預先註冊。50 人子樣本用更新的 OpenAI 模型重跑 GSS,2025 年的 GPT-4o 幾乎完全重現 2024 年結果。

## 階段 04 · 坑點:最容易做出「假的好結果」的地方

### 坑 01 沒有自我一致性基線,你的準確率無法解讀

65.67% 聽起來很爛、83% 聽起來很好,但它們是同一件事。沒有兩週回測資料,你不知道天花板在哪,也無法分辨「模型不準」與「這個人本來就善變」。

**怎麼做:** 收資料時就把回測排進流程——同一份評測題,間隔一到兩週讓本人再做一次。這是唯一取得天花板的機會,補收成本極高。

### 坑 02 資料洩漏:你以為在測模擬,其實在測檢索

論文自承 agent 的兩條路徑之一是「直接檢索」——答案早就在逐字稿裡,只是原問題主題不同。他們掃了 54,694 組配對、砍掉 27 題才敢報結果。

**怎麼做:** 評測前務必做題目重疊掃描(LLM 分類器 + 人工複核),量表型 agent 的輸入排除同題與同構念題目。沒做這步,分數不能拿來跟任何人比。

### 坑 03 訪談腳本自己設計 = 偷看考題

邊看評測任務邊調訪談題目,等於把答案寫進輸入。論文刻意採用外部設計、與評測無關的協定。

**怎麼做:** 先鎖死訪談腳本,再決定評測集(或反過來),兩者由不同的人/不同時間點決定,並記錄先後順序。

### 坑 04 兩小時訪談的邊際報酬極低

砍掉 80% 訪談內容,GSS 只從 0.83 掉到 0.79。一旦模型拿到與構念相關的資訊,再多細節也不會大幅改變預測。

**怎麼做:** 不要一開始就投入兩小時的收資料成本。先做 20–30 分鐘、覆蓋面廣的版本,量出曲線再決定加長與否。深度的價值在「覆蓋新面向」,不在「講更多」。

### 坑 05 這套架構抓的是事實,不是風格——對「行為孿生」是壞消息

逐字稿換成剝除語言特徵的條列摘要,表現只從 0.83 掉到 0.81——模型幾乎沒用到「這個人怎麼講話」。如果目標是複製語氣、回覆習慣、什麼時候懶得回,這篇的方法**沒有證據支持做得到**;它證明的是態度與選擇的預測。

**怎麼做:** 把「內容預測」與「風格模仿」當成兩個分開的問題與兩套評測。前者用本論文的 prompt-only 架構;後者才是微調(LoRA / DPO)真正有價值的地方,且需另外設計風格層評分(用詞分佈、回覆長度、已讀不回率)。

### 坑 06 「說的」預測不了「做的」:有真實利益時全軍覆沒

五個真錢經濟賽局裡,**沒有任何 agent 顯著贏過純人口統計基線**(F(4,5255)=1.63, p=0.16),量表型 agent(0.38)甚至比人口統計(0.48)差。作者稱之為「邊界案例,而非自陳資料明顯有幫助的領域」。

**怎麼做:** 不要把孿生放到「需要真實利害取捨」的位置——代為報價、代為決定花錢、代為談判。有實際成本的決策留給本人。

### 坑 07 個體準 ≠ 群體結構對

agent 能準確預測個人,但不保證能重現整個樣本的**題間相關結構**。先前研究顯示 LLM 生成的問卷回答,題目間相關性會比真人資料更強。

**怎麼做:** 想用一群孿生做「模擬受測者」或聚合分析,必須另外驗證相關矩陣,不能把個體準確率當成群體效度的證據。

### 坑 08 只驗證過 OpenAI 家族 + 英文

全部結果來自 GPT-4o;開源權重模型(Llama、Qwen)能否轉移**未經測試**。資料全是英語訪談與問卷。

**怎麼做:** 中文 + 開源模型的組合是完全未驗證的區域。復刻時要自己重跑 demographic 與 persona 兩條基線,否則不知道分數是方法帶來的還是模型帶來的。至少用同一份資料跑兩個不同底模對照。

### 坑 09 寫一段自我介紹當 system prompt,幾乎沒用

Persona 基線在 GSS 只有 0.71,甚至**低於**只給年齡性別種族政治傾向的 0.74。這是目前最常見的「數位分身」做法,而它在個體層級基本沒有增益。

**怎麼做:** 別把力氣花在把 persona 段落寫得更漂亮。把力氣拿去做結構化的自陳收集(半結構訪談或量表),那才是分數的來源。

### 坑 10 自陳資料本身沒被驗證過真假

整套方法建立在「人說的是真的」之上。社會期許偏誤、敏感資訊省略、記憶錯誤都沒被處理,論文也承認。

**怎麼做:** 在孿生輸出上標示信心來源(哪條反思、哪段逐字稿支撐這個回答),讓錯誤可追溯回原始陳述,而不是變成無法稽核的黑盒人格。

### 坑 11 訪談逐字稿無法匿名化——這是設計問題不是法遵問題

作者花六個多月與 IRB 討論,仍必須告知受訪者「即使去識別化,資訊仍可能被無意分享」,並承諾 **25 年內**受理資料移除請求。採兩層存取:量表聚合結果公開,完整逐字稿與個體 agent 只開放給經稽核 API 的研究者。

**怎麼做:** 要做「餵別人的資料就能用」的泛用框架,存取分層與撤回機制要在第一版就進架構。至少要有:原始逐字稿與衍生反思分離儲存、單一使用者的完整刪除路徑、查詢紀錄(誰在什麼時候查過)。

## 階段 05 · 落地:搬到自己的孿生專案的 8 步清單

1. **先建評測集,再建 agent** — 從自己的資料挑 100–150 題有明確標準答案的選擇題(態度、偏好、判斷),選項數 3–5。這是整個專案的量尺。
2. **兩週後把同一份評測再做一次** — 取得自我一致率。無法事後補做,它直接告訴你天花板在哪。
3. **跑三條基線** — 人口統計、自我介紹段落、純底模無資料。任何新方法都要贏過這三條才算數。
4. **做重疊掃描** — 輸入資料與評測題兩兩配對,用 LLM 找近似措辭並人工複核,記錄砍掉幾題。
5. **換掉四位專家** — 論文的四位專家是為社會科學評測設計的。行為孿生應換成貼近目標的角色,例如「工具使用習慣」「溝通與回覆模式」「品味與推薦傾向」「日常時間分配」,各生成 5–20 條反思並存檔。
6. **照抄四步 CoT 與主題路由** — 先分類問題屬於哪位專家 → 取該專家全部反思 → 四步推理。實作成本極低,卻是分數的主要來源。
7. **Context 組裝要有取捨策略** — 論文用「反思 + 最後 5,000 字元」。原始資料若是散落的檔案與對話,等價作法是「反思 + 最近期的原始片段」;記得中段內容其實沒被讀到——反思的品質就是資訊瓶頸。
8. **風格層另外開一條線** — 內容預測用 prompt-only;語氣與行為習慣需要另一套資料、另一套評分,且是唯一值得考慮微調的部分。
